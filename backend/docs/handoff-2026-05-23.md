Layer 2's actual job is much narrower: behavioral anomaly on cooperating aircraft (pilot deviation, mode confusion, hijack). Drafted as `backend/docs/writeup/09-the-architectural-critique.md`.

3. **Added rigorous output validation** (D-008): 5-layer stack including OpenSky scientific Dataset #6 (Olive et al., 2020 — real 7700-squawk emergencies) as an external grounding signal the model has never seen. Pre-committed the finding template to prevent retconning. Documented in 07-eval-prep.md's new "Validating beyond synthetic discrimination" section.
