# Task Boards

Check boxes off as you complete tasks. Update status at the top of each file when the week closes.

**How to use:**
- Pick up your tasks at the start of each session
- Check off items as you finish them
- If you're blocked, add a note under the task — don't leave it silently unchecked
- If a task gets cut or changes, cross it out and write why
