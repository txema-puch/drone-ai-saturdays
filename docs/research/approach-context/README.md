# Contextual approach-screening iteration

This iteration tested whether public weather and aircraft metadata could make the
rules-first evidence more interpretable. NOAA QNH and OpenSky aircraft type passed
their source gates; wind coverage missed its target, while configuration, actual mass,
and ATC clearance had no adequate public observed source.

The contextual release is published for research and label collection, but it has no
fresh untouched holdout or independent labels and is not operationally qualified.
